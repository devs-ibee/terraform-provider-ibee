# ibee_nat_gateway (Resource)

A NAT gateway in a VPC. A VPC created with connectivity_type nat_gateway already has one (ibee_vpc.default_nat_gateway_id); use this resource to import a gateway or to create one, and the API decides whether it is allowed. Import as vpc_id/nat_gateway_id. Mutations use upstream billing and lifecycle admission without client eligibility probes. Pricing, affordability, entitlement and quota enforcement remain authoritative on the server.
