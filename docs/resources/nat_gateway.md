# ibee_nat_gateway (Resource)

A separately managed NAT gateway. Current deployments require a nat_gateway VPC, whose creation already creates a gateway: normally use ibee_vpc.default_nat_gateway_id directly. Use this resource to import an existing gateway or recreate one after explicit removal; creation refuses to adopt an existing gateway. Do not manage the same gateway here and as a VPC-owned default. Import as vpc_id/nat_gateway_id. Remove VM attachments and forwarding rules before deletion. Mutations use upstream billing and lifecycle admission without client eligibility probes. Pricing, affordability, entitlement and quota enforcement remain authoritative on the server.
