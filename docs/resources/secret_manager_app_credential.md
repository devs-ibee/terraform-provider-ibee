# ibee_secret_manager_app_credential (Resource)

A Secret Manager app credential (AppRole) that an application uses to sign in to the workspace's Vault API. Create waits until it is active, then issues a secret ID once and keeps it in state with the role ID (`secret_id` is sensitive but not encrypted by the provider; use an encrypted state backend). Every input change replaces the credential; to rotate the secret ID, replace the resource. Reads never return the secret ID; imports leave it null. Destroy revokes the credential: new sign-ins stop at once. Import with the credential ID.

## Example Usage

```terraform
# An AppRole login for an application. The secret ID is issued once, kept in
# state (sensitive) and not recovered by import. Destroy revokes the credential.
resource "ibee_secret_manager_app_credential" "billing" {
  name   = "billing-app"
  access = "read"
  folder = "apps/billing"
}

output "role_id" {
  value = ibee_secret_manager_app_credential.billing.role_id
}

output "secret_id" {
  value     = ibee_secret_manager_app_credential.billing.secret_id
  sensitive = true
}
```
