# ibee_container_registry (Resource)

A Container Registry registry. Images live at registry.ibee.ai/<name>/<repository>:<tag>. The registry service decides names, plans (it asks Billing), visibility and states, and the provider relays its answer. Create waits until observed_state is ACTIVE. visibility and vulnerability_pull_policy change in place, and a new sku_code is sent as a plan upgrade (the API accepts larger plans only). Destroy deletes the registry, which must be empty, and waits until the API reports it deleted; the name is never reused. Import with the registry ID.

## Example Usage

```terraform
resource "ibee_container_registry" "apps" {
  name                      = "acme-apps"
  sku_code                  = "REGISTRY-STORAGE-250GB"
  visibility                = "PRIVATE"
  vulnerability_pull_policy = "BLOCK_CRITICAL"
}
```

## Schema

| Attribute | Type | Behavior | Description |
| --- | --- | --- | --- |
| `acknowledge_public_egress_charges` | `bool` | Optional | Sent with create and with a visibility change. The API requires true for PUBLIC, because anonymous pull bandwidth is billed to the workspace. |
| `id` | `string` | Read-only | Registry ID. |
| `name` | `string` | Required | Globally unique registry name. It cannot be changed, so a change replaces the registry. |
| `observed_state` | `string` | Read-only | Provisioning state the API reports, for example ACTIVE. |
| `sku_code` | `string` | Required | Storage plan SKU, for example REGISTRY-STORAGE-250GB. A change is sent as a plan upgrade with an Idempotency-Key; the API refuses smaller plans and a second pending change. |
| `visibility` | `string` | Optional, Defaulted | PRIVATE or PUBLIC. The API default (PRIVATE) applies when omitted. Changes in place. |
| `vulnerability_pull_policy` | `string` | Optional, Defaulted | ALLOW, BLOCK_CRITICAL, BLOCK_HIGH, BLOCK_MEDIUM or BLOCK_LOW. The API default applies when omitted. Changes in place. |
