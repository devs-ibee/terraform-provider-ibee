# ibee_cloud_vm (Resource)

A cloud VM. A plan_id change resizes the VM in place and an ssh_key_ids change updates its access in place; the API decides whether a change is allowed and stops and starts the VM when it must. Other configuration changes replace the VM. Imports use the VM ID.

## Example Usage

```terraform
resource "ibee_cloud_vm" "web" {
  name             = "web"
  site_id          = "SITE_ID"
  plan_id          = "PLAN_ID"
  template_id      = "TEMPLATE_ID"
  os_distro        = "ubuntu"
  billing_interval = "HOURLY"
  ssh_key_ids      = ["SSH_KEY_ID"]
}
```
