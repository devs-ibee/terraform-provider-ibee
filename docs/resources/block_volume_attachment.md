# ibee_block_volume_attachment (Resource)

Attaches a standalone block volume to a canonical storage node. This storage operation exposes a device on the node; it does not hot-plug or mount a VM guest. For VM guest integration use the cloud/GPU VM volume attachment resource. Do not manage one attachment through both APIs. Destroy requires explicit unmount acknowledgement and never forces detach. Import using VOLUME_ID/NODE_NAME.
