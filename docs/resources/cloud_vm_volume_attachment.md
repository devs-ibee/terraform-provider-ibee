# ibee_cloud_vm_volume_attachment (Resource)

Attaches an existing block volume to a VM. Destroy detaches the volume without deleting it. The guest must be unmounted before destruction. Import using VM_ID/VOLUME_ID. Read requires the backend VM data_volumes projection.
