# ibee_block_volume (Resource)

A standalone block-storage volume. A size_gb change resizes the existing volume in place; the API refuses changes it cannot make, such as shrinking, and the volume is never replaced for a size change. Destroy refuses attached volumes and never forces detachment. SKU admission uses the server catalog without a client-invented price. Currency and pricing are resolved upstream. Import using the volume ID.
