# ibee_block_volume (Resource)

A standalone block-storage volume. Size increases resize the existing volume; decreases replace it. Destroy refuses attached volumes and never forces detachment. SKU admission uses the server catalog without a client-invented price. Currency and pricing are resolved upstream. Import using the volume ID.
