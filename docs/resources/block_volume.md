# ibee_block_volume (Resource)

A block-storage volume. A size_gb change is sent to the resize operation; the API decides which changes it accepts. Destroy deletes the volume; the API decides whether an attached volume can be deleted. Import using the volume ID.

<!-- Generated by scripts/generate_docs.py; edit schema descriptions in Go. -->

## Example Usage

```terraform
data "ibee_block_storage_plans" "all" {
  site_id = "SITE_ID"
}

resource "ibee_block_volume" "data" {
  name     = "data"
  site_id  = "SITE_ID"
  sku_code = data.ibee_block_storage_plans.all.plans[0].sku_code
  size_gb  = 100
}
```
