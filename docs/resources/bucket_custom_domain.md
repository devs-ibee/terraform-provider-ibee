# ibee_bucket_custom_domain (Resource)

A custom hostname that serves a public bucket's files (the API refuses one on a private bucket). Create the domain's CNAME record first: the API checks it when the domain is added, and its refusal names the target to point it at (the portal's Custom domains tab shows it too). The service then issues TLS (status). Destroy removes the hostname from the bucket. Import with BUCKET_NAME/DOMAIN.

## Example Usage

```terraform
# The bucket must be public, and the domain's CNAME record must exist first: the
# API checks it when the domain is added (its refusal names the target).
resource "ibee_bucket_custom_domain" "assets" {
  bucket_name = "my-assets"
  domain      = "assets.example.com"
}

output "cname_target" {
  value = ibee_bucket_custom_domain.assets.cname_target
}
```
