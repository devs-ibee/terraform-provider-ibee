# ibee_bucket_custom_domain (Resource)

A custom hostname that serves a bucket's public files. Create the CNAME record shown in cname_target at your DNS provider; the service checks it and issues TLS (status). Destroy removes the hostname from the bucket. Import with BUCKET_NAME/DOMAIN.

## Example Usage

```terraform
resource "ibee_bucket_custom_domain" "assets" {
  bucket_name = "my-assets"
  domain      = "assets.example.com"
}

# Create a CNAME record for assets.example.com that points here.
output "cname_target" {
  value = ibee_bucket_custom_domain.assets.cname_target
}
```

| Attribute | Type | Behavior | Description |
| --- | --- | --- | --- |
| `bucket_name` | `string` | Required | Bucket name. |
| `cname_target` | `string` | Read-only | Hostname the domain's CNAME record must point at. |
