# ibee_bucket (Resource)

An IBEE object storage bucket. Destroy deletes the bucket (DELETE /object-storage/buckets/{name}); the API decides whether it can be deleted, for example it refuses a bucket with object lock. Manage lifecycle, CORS and notification rules with ibee_bucket_lifecycle, ibee_bucket_cors and ibee_bucket_notifications. Import using the bucket name.

## Example Usage

```terraform
resource "ibee_bucket" "assets" {
  name   = "my-assets"
  region = "REGION"
}

# Object lock is chosen at creation; the default retention can be changed later.
resource "ibee_bucket" "records" {
  name                = "my-records"
  region              = "REGION"
  object_lock_enabled = true
  default_retention = {
    mode = "GOVERNANCE"
    days = 30
  }
}
```
