# ibee_load_balancer_l4 (Resource)

An IBEE l4 load balancer. Import using the load balancer ID. Sends name, protocol, backends (and rules for l7); the API decides defaults and what it accepts. TLS, routing-policy and health-check settings are not managed by this resource. Mutations use upstream billing and lifecycle admission without client eligibility probes. Pricing, affordability, entitlement and quota enforcement remain authoritative on the server.

## Example Usage

```terraform
resource "ibee_load_balancer_l4" "tcp" {
  name     = "tcp"
  protocol = "tcp"
  backends = [{
    type   = "ip"
    target = "10.0.0.10"
    port   = 443
  }]
}
```
