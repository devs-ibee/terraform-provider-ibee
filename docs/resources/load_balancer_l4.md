# ibee_load_balancer_l4 (Resource)

An IBEE l4 load balancer. Import using the load balancer ID. Supports readable backend and routing-rule fields. HTTPS uses managed TLS termination and tls_passthrough uses passthrough TLS. Certificate material and routing-policy configuration cannot be refreshed through the public read contract. Mutations use upstream billing and lifecycle admission without client eligibility probes. Pricing, affordability, entitlement and quota enforcement remain authoritative on the server.
