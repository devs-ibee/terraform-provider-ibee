# ibee_load_balancer (Resource)

A regional load balancer, declared as one specification. Create and update send the whole specification (update with the API's current version) and wait for the operation to finish; destroy deletes the load balancer and waits. The service decides defaults, what it accepts and the node-hour price, and the provider relays its answer. Targets are VMs, or private addresses in your VPC where the region's capabilities.private_targets is true (ibee_load_balancer_regions); a target the region cannot reach is refused with 422 target_not_usable. address is the public IP to point DNS at. Import with the load balancer ID. Mutations use upstream billing and lifecycle admission without client eligibility probes. Pricing, affordability, entitlement and quota enforcement remain authoritative on the server.

## Example Usage

```terraform
data "ibee_load_balancer_regions" "available" {}

variable "web_vm_ids" {
  description = "VMs with their own public IP that serve the site."
  type        = list(string)
}

# Each node is billed per hour; node_count sets how many run.
resource "ibee_load_balancer" "web" {
  name         = "web"
  region_id    = data.ibee_load_balancer_regions.available.ids[0]
  traffic_type = "http"

  listeners = [{
    name         = "http"
    protocol     = "HTTP"
    port         = 80
    target_group = "app"
    rules        = [{ path_prefix = "/api", target_group = "api" }]
  }]

  target_groups = [
    {
      name     = "app"
      protocol = "HTTP"
      targets  = [for id in var.web_vm_ids : { kind = "vm", resource_id = id, port = 8080 }]
      # unhealthy_threshold is left to the server (1 for HTTP, 3 for TCP).
      health_check = { protocol = "HTTP", path = "/healthz", hostname = "app.example.com", expected_statuses = [200, 204] }
    },
    {
      name     = "api"
      protocol = "HTTP"
      targets  = [for id in var.web_vm_ids : { kind = "vm", resource_id = id, port = 8081 }]
    },
  ]

  # Only these sources reach the listener; leave firewall out to accept everyone.
  firewall = {
    mode  = "restricted"
    rules = [{ address_family = "IPv4", protocol = "TCP", source = "203.0.113.0/24", port = 80 }]
  }
}

# Point an A record for your domain at this address.
output "load_balancer_address" {
  value = ibee_load_balancer.web.address
}
```
