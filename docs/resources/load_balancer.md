# ibee_load_balancer (Resource)

A regional load balancer, declared as one specification. Create and update send the whole specification (update with the API's current version) and wait for the operation to finish; destroy deletes the load balancer and waits. The service decides defaults, what it accepts and the node-hour price, and the provider relays its answer. Targets are private addresses or VMs in your VPC. Import with the load balancer ID. Mutations use upstream billing and lifecycle admission without client eligibility probes. Pricing, affordability, entitlement and quota enforcement remain authoritative on the server.

## Example Usage

```terraform
data "ibee_load_balancer_regions" "available" {}

# Each node is billed per hour; node_count sets how many run.
resource "ibee_load_balancer" "web" {
  name         = "web"
  region_id    = data.ibee_load_balancer_regions.available.ids[0]
  traffic_type = "http"

  listeners = [{
    name         = "http"
    protocol     = "HTTP"
    port         = 80
    target_group = "app"
    rules        = [{ path_prefix = "/api", target_group = "api" }]
  }]

  target_groups = [
    {
      name         = "app"
      protocol     = "HTTP"
      targets      = [{ kind = "ip", address = "10.0.0.10", port = 8080 }]
      health_check = { protocol = "HTTP", path = "/healthz" }
    },
    {
      name     = "api"
      protocol = "HTTP"
      targets  = [{ kind = "ip", address = "10.0.0.11", port = 8081 }]
    },
  ]
}
```
