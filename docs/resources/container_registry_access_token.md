# ibee_container_registry_access_token (Resource)

A Container Registry access token: a docker login credential for registry.ibee.ai. The registry service decides what is allowed (it asks Billing at creation). Every input change replaces the token. The username and secret are returned once, at creation, and kept in state (secret is sensitive but not encrypted by the provider; use an encrypted state backend). Reads list the registry's tokens and never return the secret; imports leave it null. A revoked token, or one the list no longer shows, leaves state. Destroy revokes the token. Import with REGISTRY_ID/TOKEN_ID.

## Example Usage

```terraform
resource "ibee_container_registry_access_token" "ci" {
  registry_id     = "REGISTRY_ID"
  name            = "ci-push"
  permission      = "PULL_PUSH"
  expires_in_days = 90
}

# docker login registry.ibee.ai -u "$(terraform output -raw registry_username)"
output "registry_username" {
  value = ibee_container_registry_access_token.ci.username
}
```
