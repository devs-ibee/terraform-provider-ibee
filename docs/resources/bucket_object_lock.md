# ibee_bucket_object_lock (Resource)

The default retention of a bucket created with object lock: new objects can't be deleted or overwritten until it ends. Create and update set it (PUT); destroy removes the default retention (objects already locked stay locked). The service decides what a bucket allows. Import with the bucket name.

## Example Usage

```terraform
resource "ibee_bucket" "records" {
  name                = "my-records"
  region              = "STORAGE_REGION"
  object_lock_enabled = true
}

# New objects can't be deleted or overwritten for 30 days.
resource "ibee_bucket_object_lock" "records" {
  bucket_name = ibee_bucket.records.name
  mode        = "GOVERNANCE"
  days        = 30
}
```
