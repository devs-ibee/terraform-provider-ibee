# ibee_firewall_rule (Resource)

A rule inside an IBEE firewall group. Settings that are not configured are not sent and the API's defaults apply. direction, protocol and action replace the rule; other changes are sent with PATCH. Import as firewall_group_id/rule_id.

## Example Usage

```terraform
resource "ibee_firewall_rule" "https" {
  firewall_group_id = "FIREWALL_GROUP_ID"
  direction         = "ingress"
  protocol          = "tcp"
  port_start        = 443
  port_end          = 443
  remote_targets    = ["0.0.0.0/0"]
  action            = "allow"
}
```
