# ibee_s3_credential (Resource)

An S3 access key pair. The API has no update operation, so any input change replaces the key. Settings that are not configured are not sent and the API's defaults apply. The secret_access_key is returned once, at creation, and kept in Terraform state (sensitive, not encrypted by the provider; use an encrypted state backend); imports leave it null. Destroy revokes the key (POST .../revoke) and then deletes it (DELETE). Import using the access key ID.
