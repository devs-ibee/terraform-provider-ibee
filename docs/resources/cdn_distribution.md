# ibee_cdn_distribution (Resource)

An IBEE CDN distribution backed by a bucket or custom origin. Origin changes replace the distribution. Destroy deletes the distribution; it never deletes the origin. Mutations use upstream billing and lifecycle admission without client eligibility probes. Pricing, affordability, entitlement and quota enforcement remain authoritative on the server.
