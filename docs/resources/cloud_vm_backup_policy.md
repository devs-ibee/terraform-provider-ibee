# ibee_cloud_vm_backup_policy (Resource)

Enables (backups/enable) and updates (PATCH backups/policy) automated backups of a VM. Settings that are not configured are not sent, so the API's defaults apply, and are read back from the API. Destroy disables backups (backups/disable); existing recovery points are kept and may continue to be billed. Import using the VM ID.

## Example Usage

```terraform
data "ibee_backup_storage_plans" "all" {}

resource "ibee_cloud_vm_backup_policy" "web" {
  vm_id           = "VM_ID"
  frequency       = "daily"
  hour            = 2
  retention_days  = 7
  billing_catalog = data.ibee_backup_storage_plans.all.plans[0].billing_catalog
}
```
