# ibee_cdn_domain (Resource)

A custom domain associated with a CDN distribution. DNS ownership validation and TLS issuance remain asynchronous; this resource reports their status without claiming the domain is ready. Set the required CNAME at your DNS provider. Import using DISTRIBUTION_ID/DOMAIN. Destroy removes the association, not DNS records.
