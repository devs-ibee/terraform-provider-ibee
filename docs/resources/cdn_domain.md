# ibee_cdn_domain (Resource)

A custom domain of a CDN distribution. The API validates DNS and issues TLS asynchronously; status reports where it is. Set the CNAME the API returns at your DNS provider. Import using DISTRIBUTION_ID/DOMAIN. Destroy removes the domain from the distribution, not DNS records.
