# ibee_secret (Resource)

An IBEE secret with a write-only JSON value (Terraform 1.11+). Values are never stored in plan or state. Change value_wo_version to send a new value; value changes alone cannot be detected. Destroy soft-deletes the secret (DELETE). Import with the secret ID.

## Example Usage

```terraform
variable "database_password" {
  type      = string
  sensitive = true
  ephemeral = true
}

resource "ibee_secret" "database" {
  store_id         = "STORE_ID"
  secret_name      = "database-password"
  value_wo         = jsonencode({ password = var.database_password })
  value_wo_version = 1
}
```
