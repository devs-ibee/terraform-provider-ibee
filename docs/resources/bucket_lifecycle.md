# ibee_bucket_lifecycle (Resource)

The lifecycle (object expiration) rules of a bucket. An enabled rule deletes matching objects after expiration_days or on expiration_date. Create and update replace every rule of the section (PUT); destroy deletes the section (DELETE). Import using the bucket name.
