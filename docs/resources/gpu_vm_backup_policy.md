# ibee_gpu_vm_backup_policy (Resource)

Enables and manages automated VM backups. Destroy disables future backups and retains existing recovery points, which may continue incurring storage charges. Import using the VM ID. The upstream mutation decides billing and lifecycle admission.

```terraform
resource "ibee_gpu_vm_backup_policy" "worker" {
  vm_id          = "VM_ID"
  frequency      = "daily"
  hour           = 2
  retention_days = 7
  # Temporary: the API expects the backup storage SKU until it resolves it itself.

}
```
