# ibee_secret_manager (Resource)

Secret Manager for the provider's workspace. Create enables it with a namespace and waits until it is active. Enabling is permanent: the namespace and default version limit can't change afterwards, and destroy only removes the resource from Terraform state (Secret Manager stays enabled). Secret values are written and read at the workspace's Vault API (`endpoint`), never through this provider. Import with any ID; the workspace's current Secret Manager is read.

## Example Usage

```terraform
# Turns on Secret Manager for the workspace. The namespace can't change later,
# and destroy leaves Secret Manager on.
resource "ibee_secret_manager" "this" {
  namespace = "team-billing"
}

# Write and read secret values with the Vault API at this address.
output "vault_endpoint" {
  value = ibee_secret_manager.this.endpoint
}
```

## Schema

| Attribute | Type | Behavior | Description |
| --- | --- | --- | --- |
| `endpoint` | `string` | Read-only | Vault API address for secret values, when the service reports one. |
| `id` | `string` | Read-only | The workspace ID. |
| `max_versions` | `number` | Optional, Defaulted | Default number of versions kept per secret. The API default applies when omitted; it can't change after enabling. |
| `namespace` | `string` | Required | Vault namespace, 3 to 32 lowercase letters, digits or hyphens. It can't change after enabling. |
| `state` | `string` | Read-only | Secret Manager state, such as active. |
