# ibee_secret_identity_scope (Resource)

Grants a Secret Store application identity access to a store. The API decides which combinations are allowed. The public API has no operation to change a scope, so a permission change replaces it (the grant is removed and created again). Destroy removes the permission. Import with IDENTITY_ID/SCOPE_ID.
