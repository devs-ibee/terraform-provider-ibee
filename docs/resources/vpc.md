# ibee_vpc (Resource)

An IBEE VPC — an isolated Layer 3 network in a workspace. Deletion removes only default children recorded from this resource's creation. Other children must be managed separately. Import does not adopt child ownership. Managed NAT is a compound VPC create: reference default_nat_gateway_id for forwarding rules; do not declare a second NAT resource for that gateway.
