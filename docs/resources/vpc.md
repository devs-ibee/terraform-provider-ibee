# ibee_vpc (Resource)

An IBEE VPC. Settings that are not configured are not sent and the API's defaults apply. name and description change in place (PATCH); other settings replace the VPC. Destroy deletes the VPC (DELETE); the API decides what happens to its subnets and NAT gateway. Import using the VPC ID.
