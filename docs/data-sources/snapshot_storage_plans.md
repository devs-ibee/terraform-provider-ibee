# ibee_snapshot_storage_plans (Data Source)

The snapshot storage SKUs the API lists (GET /compute/plans/snapshot-storage). Pick one and pass its billing_catalog unchanged as the billing_catalog of ibee_cloud_vm_snapshot or ibee_gpu_vm_snapshot. Listing reserves nothing.

data "ibee_snapshot_storage_plans" "all" {}

}
