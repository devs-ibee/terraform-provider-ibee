# ibee_vm_access (Action)

Updates access on a cloud or GPU VM without rebooting it: adds or removes SSH keys, resets the Linux user password, or turns SSH password login on or off. Requires Terraform 1.14 or later. Invoke manually or with an explicit action trigger. Sends the fields that are set; the API decides whether the change is allowed. Waits for the operation to finish.

## Example Usage

```terraform
variable "vm_password" {
  type      = string
  sensitive = true
}

# Reset the Linux user's password and allow SSH password login.
action "ibee_vm_access" "reset_password" {
  config {
    vm_type               = "cloud"
    vm_id                 = "VM_ID"
    new_password          = var.vm_password
    password_auth_enabled = true
  }
}

# Add an inline public key.
action "ibee_vm_access" "add_key" {
  config {
    vm_type      = "cloud"
    vm_id        = "VM_ID"
    ssh_key_mode = "add"
    ssh_keys     = ["ssh-ed25519 AAAA... ops@example.com"]
  }
}

# terraform apply -invoke=action.ibee_vm_access.reset_password
```

## Schema

| Attribute | Type | Behavior | Description |
| --- | --- | --- | --- |
| `admin_username` | `string` | Optional | Linux account to update. The API uses the VM's admin user when omitted. |
| `confirm_remove_last_ssh_key` | `bool` | Optional | Confirm a removal that leaves the account without SSH keys. |
| `idempotency_key` | `string` | Optional | Optional unique request key. Reuse only when recovering the same invocation after a lost response. |
| `new_password` | `string` | Optional | New password for the Linux account. Pass it from a sensitive variable. |
| `password_auth_enabled` | `bool` | Optional | Turn SSH password login on or off. |
| `ssh_key_ids` | `list(string)` | Optional | Secret Store SSH key IDs to add or remove. For keys an ibee_cloud_vm or ibee_gpu_vm manages, change its ssh_key_ids instead, or the next apply reverts the change. |
| `ssh_key_mode` | `string` | Optional | add or remove, for ssh_keys and ssh_key_ids. |
| `ssh_keys` | `list(string)` | Optional | Inline public SSH keys to add or remove. |
| `vm_id` | `string` | Required | VM ID. |
| `vm_type` | `string` | Required | cloud or gpu. |
