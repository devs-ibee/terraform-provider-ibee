# ibee_vm_backup_create (Action)

Starts a manual cloud or GPU VM backup and waits for it to finish. Requires an enabled backup policy; the API returns 409 when backups are disabled or another run is queued or running. Requires Terraform 1.14 or later. Invoke explicitly; plan and refresh never start a backup. This action does not store a managed resource.

## Example Usage

```terraform
# The VM must have an enabled backup policy. Its stored catalog is reused.
action "ibee_vm_backup_create" "before_upgrade" {
  config {
    vm_type = "cloud"
    vm_id   = "VM_ID"
  }
}

# terraform apply -invoke=action.ibee_vm_backup_create.before_upgrade
```
