# ibee_vm_snapshot_restore (Action)

Restores a VM snapshot set. Requires Terraform 1.14 or later. Invoke manually or with an explicit action trigger; plan and refresh never restore. Sends the fields that are set and the API decides whether the restore is allowed and what each target mode needs. Waits until the API reports the restore succeeded, failed or was cancelled. A new VM created by new_vm is not managed by Terraform until you import it.

## Example Usage

```terraform
# Create a new VM from a snapshot set. target_mode is replace, new_vm or volume_only.
action "ibee_vm_snapshot_restore" "to_new_vm" {
  config {
    vm_type         = "cloud"
    vm_id           = "VM_ID"
    snapshot_set_id = "SNAPSHOT_SET_ID"
    target_mode     = "new_vm"
    target_vm_name  = "web-restored"
    target_plan_id  = "PLAN_ID"
  }
}

# terraform apply -invoke=action.ibee_vm_snapshot_restore.to_new_vm
```

## Schema

| Attribute | Type | Behavior | Description |
| --- | --- | --- | --- |
| `auto_start` | `bool` | Optional | Start the VM after the restore. The API default applies when omitted. |
| `selected_volume_id` | `string` | Optional | Volume to restore (volume_only). |
| `snapshot_set_id` | `string` | Required | Snapshot set to restore, such as ibee_cloud_vm_snapshot.id. |
| `target_cpu` | `number` | Optional | vCPUs for the new VM. |
| `target_disk_gb` | `number` | Optional | Root disk in GB for the new VM. |
| `target_gpu_count` | `number` | Optional | GPUs for a new GPU VM. |
| `target_gpu_model` | `string` | Optional | GPU model for a new GPU VM. |
| `target_mode` | `string` | Required | replace (restore over the source VM), new_vm (create a VM from the recovery point) or volume_only (restore one volume, set selected_volume_id). |
| `target_plan_id` | `string` | Optional | Plan for the new VM (new_vm), from ibee_compute_plans. |
| `target_ram_mb` | `number` | Optional | Memory in MB for the new VM. |
| `target_site_id` | `string` | Optional | Site for the new VM (new_vm). |
| `target_vm_name` | `string` | Optional | Name of the new VM (new_vm). |
| `vm_id` | `string` | Required | ID of the VM the snapshot or backup was taken from. |
| `vm_type` | `string` | Required | cloud or gpu. |
