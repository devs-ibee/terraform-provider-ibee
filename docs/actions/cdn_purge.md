# ibee_cdn_purge (Action)

Purges CDN cache (POST /cdn/distributions/{id}/purge). Requires Terraform 1.14 or later. Invoke manually or through an explicit action trigger; refresh never purges. Sends mode and the target lists that are set; the API decides what each mode needs. This action does not delete origin objects.

## Example Usage

```terraform
action "ibee_cdn_purge" "home_page" {
  config {
    distribution_id = "DISTRIBUTION_ID"
    mode            = "url"
    paths           = ["/index.html"]
  }
}

# terraform apply -invoke=action.ibee_cdn_purge.home_page
```
