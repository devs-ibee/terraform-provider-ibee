# ibee_vm_power (Action)

Starts, stops or reboots a cloud or GPU VM (POST .../actions/{operation}) and waits for the operation to finish. Requires Terraform 1.14 or later. Invoke manually or with an explicit action trigger; plan and refresh never change VM power. The API decides whether the VM can take the operation.

## Example Usage

```terraform
action "ibee_vm_power" "start" {
  config {
    vm_id     = "VM_ID"
    vm_type   = "cloud"
    operation = "start"
  }
}

# terraform apply -invoke=action.ibee_vm_power.start
```
