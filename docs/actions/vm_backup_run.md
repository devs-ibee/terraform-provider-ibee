# ibee_vm_backup_run (Action)

Runs a manual backup of a cloud or GPU VM now, using the VM's backup configuration (see ibee_cloud_vm_backup_policy). Requires Terraform 1.14 or later. Invoke manually or with an explicit action trigger; plan and refresh never run a backup. The API decides whether the run is allowed. Waits until the API reports the run succeeded, failed or was cancelled.

## Example Usage

```terraform
action "ibee_vm_backup_run" "now" {
  config {
    vm_type         = "cloud"
    vm_id           = "VM_ID"
    reason          = "Before the database upgrade"
    billing_catalog = jsonencode({ sku_id = "SKU_ID", sku_code = "SKU_CODE" })
  }
}

# terraform apply -invoke=action.ibee_vm_backup_run.now
```
