# ibee_vm_backup_restore_cancel (Action)

Cancels a queued cloud or GPU VM backup restore owned by the configured workspace. The API returns 409 if the restore is already running; this action does not terminate a running restore. Requires Terraform 1.14 or later. Invoke explicitly; plan and refresh never cancel a restore.

## Example Usage

```terraform
# Cancellation is available only while the restore is queued.
action "ibee_vm_backup_restore_cancel" "queued" {
  config {
    vm_type    = "cloud"
    restore_id = "RESTORE_ID"
  }
}

# terraform apply -invoke=action.ibee_vm_backup_restore_cancel.queued
```
